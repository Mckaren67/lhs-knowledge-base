Welcome to the Lifestyle Home Service skills check

This is a short interactive exercise to see how you approach residential cleaning. It takes about 15–20 minutes. There are no trick questions.

You will:

  • Walk through 3 rooms (kitchen, bathroom, bedroom)
  • Pick which room to start with and how you'd sequence your work
  • Estimate how long each room should take you
  • Choose tools and cloth colours from a cleaning kit
  • Click the surfaces you would clean, in the order you would clean them
No prior knowledge of our colour system is required. We'll introduce it as you go. Just clean the way you'd naturally approach it.
